# Терминальный аквариум

Анимированный ASCII-аквариум: рыбы разных видов, у каждой свой цвет и смешной ник.

## Установка

```sh
mkdir -p ~/.local/bin
ln -s "$PWD/aquarium.py" ~/.local/bin/aquarium
```

Убедитесь, что `~/.local/bin` есть в `PATH`. Нужен Python 3, других зависимостей нет.

## Запуск при открытии терминала (fish)

Создайте `~/.config/fish/functions/fish_greeting.fish`:

```fish
function fish_greeting
    aquarium
end
```

fish вызывает `fish_greeting` только в интерактивных сессиях, поэтому `scp` и скрипты не ломаются. Аквариум держит терминал, пока вы не нажмёте `q`.

## Как работает

- Первый запуск: экран выбора рыб. После Enter выбор сохраняется в `~/.config/aquarium/config.json` и открывается аквариум.
- Дальше аквариум открывается сразу с сохранённым набором.
- Сбросить выбор: `aquarium --setup`, клавиша `c` в аквариуме или удалить `~/.config/aquarium/config.json`.

## Клавиши

Экран выбора: `↑/↓` вид, `←/→` количество, пробел вкл/выкл, `r` случайный набор, `Enter` старт, `q` выход без сохранения.

Аквариум: `q` выход, `f` покормить, `p` пауза, `c` вернуться к выбору.

Окно меньше 40×12 показывает «окно слишком маленькое». Без поддержки цвета (меньше 8 цветов) рисуется без цвета.
