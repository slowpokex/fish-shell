# Терминальный аквариум

Анимированный ASCII-аквариум: рыбы разных видов, у каждой свой цвет и смешной ник.

## Установка

```sh
mkdir -p ~/.local/bin
ln -s "$PWD/aquarium.py" ~/.local/bin/aquarium
```

Убедитесь, что `~/.local/bin` есть в `PATH`. Нужен Python 3, других зависимостей нет.

## Запуск при открытии терминала (fish)

Создайте `~/.config/fish/functions/fish_greeting.fish`:

```fish
function fish_greeting
    aquarium
end
```

fish вызывает `fish_greeting` только в интерактивных сессиях, поэтому `scp` и скрипты не ломаются. Аквариум держит терминал, пока вы не нажмёте `q`.

## Как работает

- Первый запуск: экран выбора рыб. После Enter выбор сохраняется в `~/.config/aquarium/config.json` и открывается аквариум.
- Дальше аквариум открывается сразу с сохранённым набором.
- Сбросить выбор: `aquarium --setup`, клавиша `c` в аквариуме или удалить `~/.config/aquarium/config.json`.

## Клавиши

Экран выбора: `↑/↓` вид, `←/→` количество, пробел вкл/выкл, `r` случайный набор, `Enter` старт, `q` выход без сохранения.

Аквариум: `q` выход, `f` покормить, `p` пауза, `c` вернуться к выбору.

Окно меньше 50×16 показывает «окно слишком маленькое». Рыбы бывают 3–7 строк, 12 видов; глаза рисуются ярче, от рыб поднимаются пузырьки. Без поддержки цвета (меньше 8 цветов) рисуется без цвета.

## Веб-версия

В папке `web/` тот же аквариум для браузера: three.js (WebGL), 2D-графика. Рыбы — те же ASCII-рисунки с неоновым свечением, фон — шейдер с толщей воды, лучами света и песком, облачка реплик настоящие, комиксные.

Откройте `web/index.html` в браузере, сервер не нужен (three.js грузится с cdnjs). Набор рыб хранится в `localStorage`.

Клавиши те же: `f` или клик по воде — покормить, `t` или клик по рыбе — болтать, `p` — пауза, `c` — выбор рыб.

Рисунки, ники, фразы и константы веб-версия берёт из `aquarium.py`. После их правки пересоберите данные:

```sh
python3 web/build_data.py
```

## Game Boy Color

В папке `gb/` — тот же аквариум как игра для Game Boy Color. Готовый ром: `gb/aquarium.gbc`.

**Запуск на Everdrive:** скопируйте `gb/aquarium.gbc` на microSD в любую папку и выберите его в меню Everdrive. Набор рыб сохраняется в память картриджа (MBC5 + батарейка), Everdrive пишет сохранение на карту.

Что есть:

- экран выбора: до 8 рыб из 12 видов, у каждого вида свой пиксель-арт;
- рыбы с никами и цветами, пузырьки, водоросли, волна на поверхности;
- реплики в диалоговом окне внизу (ник сверху в рамке), кириллица своим шрифтом;
- корм и тычки, рыбы плывут к корму и комментируют;
- пасхалка: `B` пять раз подряд (не дольше 1,5 с между нажатиями).

Кнопки в аквариуме: `A` — покормить, `B` — ткнуть выбранную рыбу, `←/→` — выбрать рыбу (покажет ник и вид), `START` — пауза, `START` и затем `SELECT` — вернуться к выбору рыб.
На экране выбора: `↑/↓` — вид, `←/→` — количество, `SELECT` — случайно, `B` — сбросить, `A` — старт.

Сборка (нужен [GBDK-2020](https://github.com/gbdk-2020/gbdk-2020) в `tools/gbdk` или путь в `GBDK_HOME`):

```sh
python3 gb/build.py
```

Тексты, ники и скорости берутся из `aquarium.py`, графика рисуется в `gb/assets.py` (ASCII-карты пикселей). Прогон в эмуляторе со скриншотами: `gb/run_test.py` (нужен `pip install pyboy`).
