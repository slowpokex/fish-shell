# Терминальный аквариум: дизайн

## Зачем
Пользователю нужен анимированный ASCII-аквариум со случайными рыбами, у каждой из которых есть цвет и подпись с ником, как в аквариуме на скриншоте со стрима (рыбы с никами зрителей). Аквариум открывается при запуске интерактивного терминала. Нужны радость от вида и лёгкая кастомизация, а не утилита.

## Цели
- Один исполняемый скрипт `aquarium` на Python 3 со стандартной библиотекой (`curses`), без внешних зависимостей.
- Первый запуск (конфига нет): экран выбора рыб, после Enter выбор сохраняется и открывается аквариум.
- Последующие запуски (конфиг есть): экран выбора пропускается, сразу аквариум с сохранённым набором.
- Аквариум работает, пока пользователь не нажмёт клавишу выхода. Сам не закрывается.
- Рыбы плавают в обе стороны, у каждой свой цвет и подпись с ником. Ники берутся из встроенного списка смешных имён и каждый раз перемешиваются.
- Запуск из `fish_greeting` при открытии интерактивного терминала.

## Не цели
- Подключение к Twitch-чату или другому внешнему источнику ников.
- Звук.
- Акулы и другие хищники, которые едят мелких рыб.
- Поддержка Windows и других шеллов, кроме fish (zsh/bash, видимо, не нужны, но скрипт сам по себе от шелла не зависит).

## Антицели (что сделает результат провальным, даже если он работает)
- Ломает неинтерактивные запуски шелла (`scp`, скрипты): запуск только из `fish_greeting`, который fish вызывает лишь в интерактивных сессиях.
- Падает или оставляет терминал в сломанном состоянии при выходе, Ctrl+C или изменении размера окна.
- Мерцание или заметная нагрузка на процессор.

## Поведение

### Экран 1: выбор рыб
- Список видов, у каждого флажок и счётчик количества (0…N).
- Управление: `↑/↓` выбор вида, `←/→` количество, пробел включает/выключает вид, `r` случайный набор, `Enter` старт, `q` выход без сохранения.
- Макет утверждён пользователем (рамка, список видов, подсказка по клавишам внизу, кнопка «СТАРТ»).

### Экран 2: аквариум
- Рыбы разных видов плавают по горизонтали, у края разворачиваются. Скорость и вертикальная позиция случайны, цвет назначается из палитры терминала.
- Под каждой рыбой подпись с ником.
- Сверху линия поверхности воды, снизу водоросли.
- Управление: `q` выход, `f` покормить, `p` пауза, `c` вернуться к выбору рыб. Клавиши `f` и `c` заданы мной как предположение.
- Размер окна меняется на лету, рыбы пересчитываются под новый размер.

### Конфигурация
- Файл `~/.config/aquarium/config.json` (путь выбран мной), хранит виды и количество.
- Нет файла означает первый запуск, то есть показывается экран выбора.
- Повторный выбор: клавиша `c` в аквариуме или флаг `aquarium --setup`.

### Интеграция с fish
- Функция `fish_greeting` вызывает `aquarium`. Установка хука в `config.fish` отдельный шаг, не часть самого скрипта.

## Ограничения и решения
- **Язык и библиотека:** Python 3 + `curses`, зависимостей нет. Это моё решение, пользователь согласился.
- **Не берём готовый asciiquarium**: в нём нет экрана выбора и подписей. Рисунки рыб пишем сами.
- Виды рыб и список ников определяет исполнитель. Ники смешные, русские и английские, в духе IT-юмора (например, `segfault_петя`, `NullPointer_Вася`).

## Мои решения по краевым случаям (не обсуждались с пользователем)
- **Блокировка терминала:** подтверждено пользователем. Аквариум открывается при каждом новом интерактивном терминале и держит его, пока не нажата клавиша выхода.
- **Где лежит скрипт:** `~/.local/bin/aquarium`, он должен быть в `PATH`. Хук в `fish_greeting` вызывает его по имени.
- **`q` на первом экране выбора:** выходит без сохранения, конфиг не пишется, при следующем запуске выбор покажется снова.
- **Битый конфиг, неизвестный вид или сумма рыб равна нулю:** показать экран выбора, как при первом запуске.
- **Лимиты:** не больше 20 рыб на вид. Если окно слишком маленькое (меньше 50×16), вместо аквариума показывается сообщение «окно слишком маленькое», рыбы не рисуются.
- **Кормление (`f`):** сверху падает крошка корма, рыбы в радиусе плывут к ней и «съедают» её. Состояния кроме корма нет.
- **Цвета:** если терминал поддерживает меньше 8 цветов, аквариум рисуется без цвета. Ник берёт цвет своей рыбы.
- **Установка:** только README с готовым фрагментом `fish_greeting`, без команды `--install`, чтобы скрипт не трогал пользовательские файлы.
- **Тесты:** автотесты для логики без `curses` (чтение и запись конфига, перемешивание ников, расчёт движения). Восстановление терминала при выходе, Ctrl+C и изменении размера проверяется вручную.

## Оставлено исполнителю
- Точный набор видов и их ASCII-рисунки.
- Размер списка ников (не меньше нескольких десятков).
- Частота кадров и детали анимации.
- Структура кода внутри одного файла.
- Как именно устанавливать хук (инструкция в README или команда `aquarium --install`).
